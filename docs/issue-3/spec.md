# Spec — Issue #3 博客审核功能增加内容风控功能

> 来源：Issue #3 正文 + VOD 收敛结论 + issue agent Spec（2026-10-22） | 优先级 P1 | 目标分支 main

## 1. 背景与目标

博客管理员通过 MCP 工具 `hdcommunity_admin_blog_review` 审核博客时，缺少内容风控能力，
黄赌毒、政治敏感等违规内容完全依赖管理员人工判断，存在漏审发布到现网的合规风险。

目标：审核前自动执行本地内容风控，输出**风险等级 + 违规类型**，**仅标记不阻断**，管理员保留最终决定权。

## 2. 需求要点（已由 @lithinkit 澄清确认）

| 要点 | 结论 |
|---|---|
| 风控范围（第一期） | 文本（标题 + 正文）；图片风控二期 |
| 结果处理 | 标记风险（等级 + 类型），不阻断审核 |
| 触发时机 | 审核前自动执行，无需手动调用 |
| 实现形式 | 审核工具前置执行 + 独立风控 MCP 工具 |
| 硬约束 | 不引入付费方案，复杂度可控 |

## 3. 范围

### In Scope
- 文本风控引擎（本地 DFA 词库匹配，零网络、零付费）
- 独立 MCP 工具 `hdcommunity_admin_blog_risk_check`（标题+正文 → 风险报告）
- `hdcommunity_admin_blog_review` / `review_batch` 审核前自动风控，结果随审核响应返回
- 内置种子词库 + 用户可扩展词库文件（可接入社区开源词库数据）
- hd-blog-operator skill 工作流与 README 工具清单同步更新
- 单元测试（node:test 内建 runner，零新增测试依赖）

### Out of Scope
- 图片/视频风控（二期，调研结论见交付说明）
- 阻断式拦截、发布前二次检查、评论风控
- 后端 HDBlogService 侧改动（本仓为端侧工具包）
- 繁简体转换映射表（词库可自行收录繁体变体）

## 4. 验收标准（同 issue agent Spec）

- [ ] 管理员发起博客审核（单条/批量）时风控自动执行，无需手动调用
- [ ] 文本（标题+正文）输出风险等级与违规类型，随审核结果呈现
- [ ] 风控结果仅标记不阻断，管理员保留最终决定权
- [ ] 方案基于成熟开源/免费能力（DFA 引擎 + 可插拔开源词库数据），package.json 零新增付费依赖
- [ ] 图片风控范围在交付说明中明确标注（一期文本 / 二期迭代）
- [ ] 所有现有测试通过 + 新增风控功能测试覆盖

## 5. 关键约束

- 现有 admin API 面无"按 id 取正文"端点（`/agent/admin/blog/page` 列表、`records` 审计，均不含完整正文的稳定契约），
  审核工具侧采用**可选 `title`/`content` 入参 + 未提供时优雅降级（标记 skipped 并提示）** 的方式获取待审文本。
- Node ≥22，仓库现有依赖仅 `undici`，保持零新增运行时依赖（规避供应链风险，见 plan.md 选型）。
